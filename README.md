# @ouroboros/blog
[![npm version](https://img.shields.io/npm/v/@ouroboros/blog.svg)](https://www.npmjs.com/package/@ouroboros/blog) ![Custom License](https://img.shields.io/npm/l/@ouroboros/blog.svg)

Shared javascript code for interacting with the blog service created by
Ouroboros Coding Inc.

See [Releases](https://github.com/ouroboroscoding/blog-js/blob/main/releases.md)
for changes from release to release.

## Installation

Install with npm

```console
foo@bar:~$ npm install @ouroboros/blog
```

## React + Material UI
If you're connecting to blog via a [React](https://react.dev/) / MUI framework,
you might want to checkout
[@ouroboros/blog-react-mui](https://www.npmjs.com/package/@ouroboros/blog-react-mui)
which provides a Component for managing your Blog.
